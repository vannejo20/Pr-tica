Git y GitHub

Git es un programa que guarda el historial de cambios de nuestros archivos.

GitHub es una página web donde subimos nuestro repositorio para compartirlo y trabajar en equipo.

Comandos que usamos

  • git init: crea un repositorio nuevo.
  • git add: prepara los archivos para guardarlos.
  • git commit: guarda los cambios con un mensaje.
  • git status: muestra qué archivos cambiaron.
  • git log: muestra el historial de commits.
  • git push: sube los cambios a GitHub.

El repositorio

Es la carpeta del proyecto en GitHub. Aquí está este archivo HTML y todo su historial. Es donde trabajamos en equipo: cada uno hace sus commits y todos podemos ver quién cambió qué.
